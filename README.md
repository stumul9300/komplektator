# Комплектатор

Тестовый сайт для совместной работы комплектатора, дизайнера и заказчика над комплектацией интерьерного проекта.

- `index.html` — весь сайт (одна страница). Данные хранятся в Supabase.
- `supabase-setup.sql` — создание таблиц в Supabase (запускается один раз в SQL Editor).

Ссылки по ролям: в конце адреса добавьте `#kompl`, `#designer` или `#client`.

Тестовый режим: читать и менять данные может любой, у кого есть ссылка.
